📐 The Bellman Optimality Equation
$$Q^*(s, a) = \mathbb{E}\left[ r + \gamma \max_{a'} Q^*(s', a') \;\middle|\; s, a \right]$$

At every step $t$, the agent receives reward $r_t$ and transitions to state $s_{t+1}$. The loss function minimizes the Huber error between the current prediction $Q(s, a; \theta)$ and the Target Network estimate:

$$y_i = \begin{cases} r_i & \text{if } s'_i \text{ is terminal} \\ r_i + \gamma \max_{a'} Q(s'_i, a'; \theta^-) & \text{otherwise} \end{cases}$$

// Blazing fast cache-friendly forward pass in native JS
forward(x) {
  // Layer 1: 16 -> 64 with ReLU
  for (let j = 0; j < 64; j++) {
    let s = this.b1[j];
    const off = j * 16;
    for (let i = 0; i < 16; i++) s += this.W1[off + i] * x[i];
    this.h1[j] = s > 0 ? s : 0;
  }
  // Layer 2: 64 -> 32 with ReLU
  for (let j = 0; j < 32; j++) {
    let s = this.b2[j];
    const off = j * 64;
    for (let i = 0; i < 64; i++) s += this.W2[off + i] * this.h1[i];
    this.h2[j] = s > 0 ? s : 0;
  }
  // Layer 3: 32 -> 3 Linear Q-values
  for (let j = 0; j < 3; j++) {
    let s = this.b3[j];
    const off = j * 32;
    for (let i = 0; i < 32; i++) s += this.W3[off + i] * this.h2[i];
    this.out[j] = s;
  }
  return this.out;
}
LESSON 01
Markov Decision Processes (MDP)

Reinforcement learning frames decision-making as an MDP consisting of States $(S)$, Actions $(A)$, Rewards $(R)$, and Transition probabilities $(P)$. The Markov property asserts that the future depends solely on the current state and action.

LESSON 02
Exploration vs. Exploitation (ε-Greedy)

Early on ($\epsilon = 1.0$), the agent takes random moves to explore the state space. As episodes progress, $\epsilon$ decays exponentially to $0.01$, transitioning from discovery to ruthless policy execution.

LESSON 03
Experience Replay & Decorrelation

Consecutive game frames are heavily correlated. Storing transitions $(s, a, r, s', d)$ in a 20,000-sample circular memory and randomly batching break temporal correlations, stabilizing backpropagation.

LESSON 04
Why Pure CPU is Faster Here

For small neural networks (3,267 parameters), GPU dispatch overhead and WebGL texture readback introduce 5–15 ms latency per step. Handcrafted CPU Float32Array SIMD operations complete in 0.002 ms—over 500× faster for reinforcement learning loops!
